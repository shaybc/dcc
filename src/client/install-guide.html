Install Continue.dev definitions from DCC Hub

After the extension/plugin is installed, use DCC Hub to add Continue definitions to your project workspace.

  1. Open DCC Hub and select your target project in the Dev project picker.
  2. Browse the available definitions and open a definition details page.
  3. Click Install definition in current project to copy it into the selected project.
  4. Repeat for the set of definitions your team needs (models, prompts, rules, context, workflows, and more).
  5. In your IDE with Continue enabled, reload the workspace so Continue picks up the new project definitions.
