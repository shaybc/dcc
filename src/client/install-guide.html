Continue Extension Install Guide

Choose your IDE to see the correct installation steps for the Continue extension files bundled in this DCC repository.

1) Install the Continue extension in your IDE

Select your IDE type below. The steps update automatically.

Changing the selection updates the installation steps.

2) Install Continue definitions into a project via DCC Hub

  1. Open DCC Hub and select the target project from the Dev project selector.
  2. Find the definition you need and open its details page.
  3. Click Install definition in current project.
  4. Repeat for other definition types (models, prompts, rules, docs, context, workflows, etc.).
  5. Reload your IDE workspace so Continue re-reads the installed project definitions.
