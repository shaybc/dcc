Install Continue extension in your IDE

Install Continue.dev definitions into a project via DCC Hub

  1. Open DCC Hub and pick the target project from the Dev project selector.
  2. Find a definition you need and open its details page.
  3. Click Install definition in current project to add it to the selected project.
  4. Repeat for all required definition types (models, prompts, rules, docs, context, workflows, etc.).
  5. Reload your IDE workspace so Continue re-reads the installed project definitions.
