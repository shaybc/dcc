# Activity Page

Use the **Activity** top navigation tab to monitor runs and manage them after launch.

## What you can do

- View all runs across statuses: **All**, **Running**, **Launched**, **Finished**, and **Cancelled**.
- See quick counters for each status in the stats strip.
- Open a run to inspect metadata (agent/config, PID, duration, exit code, paths, and command line).
- Control runs with **Stream**, **Re-run**, and **Cancel** actions.

## Stream panel

From a selected run, click **Stream** to open the stdout stream panel.

In stream view, you can:

- toggle line **wrap**,
- **clear** logs,
- **copy** logs,
- toggle scroll **lock**,
- **export** logs,
- and **close** the stream panel.

## Suggested workflow

1. Open **Activity**.
2. Filter to a status (for example **Running**).
3. Select a run from the list.
4. Open **Stream** to inspect live output.
5. Use **Re-run** or **Cancel** if needed.
