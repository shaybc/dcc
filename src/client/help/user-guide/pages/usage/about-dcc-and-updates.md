# About DCC and Updates

Use the **About** option in the main menu to open the About DCC dialog.

## What you can see

- current app version,
- last release date,
- update status text and icon.

## Update flow

When an update is available, the modal exposes an **Update DCC** action.

General behavior:

1. Open **About** from the main menu.
2. Wait for update check to complete.
3. If prompted, click **Update DCC**.
4. Follow post-update prompts shown by the app.

## Closing the modal

You can close the About modal with:

- the close button,
- outside-click on the overlay,
- or **Esc**.
