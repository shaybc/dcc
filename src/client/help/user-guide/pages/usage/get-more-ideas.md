# Get More Ideas

Use **Get ideas** from the main menu to open the **Get more Ideas** dialog.

## Purpose

This modal provides quick outbound links to external idea sources for prompts, hubs, and MCP servers.

## How to use

1. Open main menu.
2. Click **Get ideas**.
3. Open one of the listed links in a new browser tab.
4. Return to DCC and create/import definitions based on what you found.

## Closing the modal

You can close the dialog with:

- the close button,
- outside-click on the overlay,
- or **Esc**.
