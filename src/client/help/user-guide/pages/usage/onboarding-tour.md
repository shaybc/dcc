# Onboarding Tour

DCC includes an in-app onboarding tour that highlights core navigation and controls.

## How to start

- The tour may run automatically for new users.
- You can also open it from the main menu via **Quick intro**.

## Tour behavior

The tour uses a spotlight overlay and popover with:

- step title,
- short description,
- **Next** and **Skip** actions.

Covered areas include top navigation, project selection, definition cards, create menu, recommendations, filters, and key main-menu entries.

## Completion

After completion (or skip), DCC records onboarding as seen so it does not keep auto-opening on every visit.
