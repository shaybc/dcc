# Definition Details Actions

This topic covers the 'Definition Details' page, you can click each definition card on the main DCC Hub page and reach that definition details page - which includes:
- overview details
- definition source
- actions that can be performed on the definition

Use these links as a quick reference to **Definition details** parts:

- [Navigation and View Controls](/user-guide.html?page=definition-details-actions-navigation-and-view-controls) - overview of the Definition Details page.
- [Definition Action Buttons](/user-guide.html?page=definition-details-actions-action-buttons) - including edit, delete, duplicate...
- [Source Tab](/user-guide.html?page=definition-details-actions-source) - view the YAML or Markdown definition source.
- [Test Tab](/user-guide.html?page=definition-details-actions-test) - test the definition lint and schema structure validity.
