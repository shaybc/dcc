# Definition Details Actions

Use this mini-index to explore all controls available on the definition details page.

## Rule attribute quick reference

For **rule** definitions, remember these key properties when creating, editing, testing, or reviewing source:

- **`globs`**: include rule when file-path patterns match.
- **`regex`**: include rule when file-content patterns match.
- **`alwaysApply`**: controls always-on vs conditional inclusion.
