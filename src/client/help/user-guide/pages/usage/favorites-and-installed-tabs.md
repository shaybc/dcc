# Favorites and Installed Tabs

DCC includes dedicated top navigation modes for **Installed** and **Favorites**.

## Installed tab

Use **Installed** to focus on definitions already installed in your active development project.

Typical uses:

- verify what is already present in a project,
- quickly open installed definitions for inspection,
- narrow day-to-day work to project-ready items.

## Favorites tab

Use **Favorites** to focus on definitions you marked for repeated use.

Typical uses:

- keep a short list of frequently used definitions,
- quickly revisit preferred prompts/agents/configs,
- reduce search overhead in large hubs.

## Notes

- Both tabs are navigation modes from the top bar, not just filters inside a page.
- Badge counters on tabs show quick volume context.
